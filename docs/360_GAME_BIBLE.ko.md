# 360 — 게임 바이블

`public/game-list/360/`의 기획 문서입니다. 원작 설정 메모에서 정해진 것과 아직 열어 둔 것을 나누고, 게임으로 옮기면서 내린 결정을 적습니다.

## 1. 한 줄 소개

죽은 뒤의 어둠에서 삶 하나를 통째로 기억하고, 그중 하나만 쥐고 나아간다. 다음 사람은 까닭도 모른 채 그 하나대로 산다.

## 2. 왜 재미있는가

- 플레이어는 어둠에서 방금 끝난 삶의 후회 가운데 하나를 고릅니다. 다음 장에서는 전혀 다른 시대의 다른 사람이 되고, 그 사람은 아무것도 기억하지 못합니다.
- 고른 하나는 다음 삶에서 **할 수 없는 선택**으로 돌아옵니다. 선택지는 화면에 그대로 있지만, 고르면 손목이 돌아가지 않거나 발이 문지방을 넘지 못합니다. 인물은 이유를 모르고, 플레이어만 압니다.
- 전생에서 얻은 답이 다음 삶의 문제가 됩니다. 굶주림을 겪고 "쥐고 있었어야 했다"를 남기면 곳간을 열지 못하는 객주가 되고, "곁에 있었어야 했다"를 남기면 딸 곁을 못 떠나 가진 것을 잃는 객주가 됩니다. 어느 쪽도 정답이 아닙니다.
- 마지막 장에서 전생을 기억한다는 사람이 주인공의 전생을 단정합니다. 플레이어는 그 말이 틀렸다는 것을 압니다. 직접 살아 봤기 때문입니다.

## 3. 원작 설정에서 지킨 것

| 원칙 | 게임에서 |
| --- | --- |
| 도입은 "암흑. 끊임없는 공허함. 눈을 떴다." | 첫 세 줄 그대로 |
| 이곳이 어디인지 설명하지 않는다 | 장소 이름을 붙이지 않고 넓이와 고요만 적는다. `src/threeSixtyGame.test.ts`가 대본에 '환생', '다시 태어', '우주'가 없는지 검사한다 |
| 몸이 없다는 묘사를 되풀이하지 않는다 | 한 번도 쓰지 않는다 |
| 고르는 순간에 다시 태어난다고 말하지 않는다 | 고르면 기울어지고 빨라질 뿐이다. 다음 화면은 연도와 지명 카드다 |
| 멈추는 것은 소멸이 아니다 | 모든 어둠에 "쥐지 않는다"가 있고, 한 번 되물은 뒤 결말 「머무름」으로 간다. 게임 오버가 아니다 |
| 신도 관리자도 없다 | 어둠에는 목소리가 없다. 안내 문구도 없다 |
| 다음 삶의 조건은 고를 수 없다 | 시대·나라·성별·집안은 장마다 정해져 있다 |
| 과거의 인연을 다시 만나지 않는다 | 다섯 삶의 인물은 서로 겹치지 않는다 |
| 깨달음이 좋은 삶을 보장하지 않는다 | 어느 방향을 골라도 그 삶은 새 후회로 끝난다 |
| 현대에 늘어난 것인지, 이제야 듣는 것인지 | 4장에서 1931년 진료부가 나오지만 숫자가 없어 답하지 못한다. 열어 둔다 |

게임에서 새로 정한 것은 두 가지입니다. 원작 메모의 "가속 중에는 선택을 바꾸기 어렵다"와 "기억 소멸 오류"를 이어, **기억하는 사람은 모두 가다가 돌아본 사람**으로 두었습니다. 그리고 다섯 번째 어둠에서 쥘 수 있는 것을 첫 번째 어둠과 같은 두 가지로 두어, 같은 것을 쥐면 결말 「한 바퀴」가 됩니다.

## 4. 형질과 각도

여덟 방향에 각도를 하나씩 붙였습니다. 어둠에서 고르면 화면 위쪽 장소 표시 자리에 숫자만 잠깐 뜹니다. 설명은 4장에서 전직 수학 교사의 녹취("지구본에 점 하나 찍는 거지")로만 나옵니다.

| 어둠 | 쥘 수 있는 것 | 상태값 | 각도 |
| --- | --- | --- | --- |
| 첫 번째 (굶주린 겨울) | 독이 비지 않았더라면 / 그날 나가지 않았더라면 | `v0: hold` / `kin` | 041.2 / 223.7 |
| 두 번째 (제물포) | 말을 했어야 했다 / 어디에도 매이지 말았어야 했다 | `v1: say` / `free` | 118.5 / 307.9 |
| 세 번째 (부산) | 아무도 믿지 말았어야 했다 / 떠나지 말았어야 했다 | `v2: guard` / `stay` | 076.3 / 251.0 |
| 네 번째 (병동) | 더 살고 싶었다 / 한 번은 해 볼걸 | `v3: live` / `dare` | 164.8 / 339.4 |
| 다섯 번째 (편집실) | 쥐고 있었어야 했다 / 곁에 있었어야 했다 | `v4: hold` / `kin` | 041.2 / 223.7 |

## 5. 다섯 삶

주인공은 화면에 그려지지 않습니다. 이름표만 있고, 서 있는 자리는 비어 있습니다. 나머지 인물은 얼굴이 없는 종이 오림입니다.

### 0. 굶주린 겨울 (`0.yaml` 앞부분)

어둠에서 떠오르는 기억 다섯 줄로만 나옵니다. 아이를 덮어 두고 강 건너로 곡식을 꾸러 갔고, 돌아왔을 때 불이 꺼져 있었습니다.

### 1장 「곳간 열쇠」 (`0.yaml`) — 1894년 제물포

- 장만석(40), 객주 주인. 딸 끝순(16), 서기 봉구.
- 유월, 포구에 군함이 들어오고 쌀값이 열흘 새 곱절이 됩니다. 곳간에 삼백열두 섬.
- 선택 `l1_rice`: 외상으로 쌀을 풀 것인가. `hold`는 곳간을 열지 못합니다.
- 선택 `l1_leave`: 학질로 누운 딸을 두고 마포에 큰 거래를 하러 갈 것인가. `kin`은 문지방을 넘지 못합니다.
- 끝: `gone`(거래는 했고 딸은 그사이 죽었다) / `kept`(쌀도 딸도 지켰지만 딸은 시집간 뒤 오지 않는다) / `poor`(곁을 지켰지만 망했고, 딸은 정미소에서 일하다 스물여섯에 눕는다. 약값 스무 냥이 없다).

### 2장 「부두」 (`1.yaml`) — 1952년 부산

- 순임(29), 흥남에서 내려온 피란민. 국제시장 좌판. 시어머니, 아들 영호(7), 미군부대 통역이라는 기호.
- 선택 `l2_heart`: 서울 점방 보증금을 맡기며 영수증을 받을 것인가, 마음을 먼저 물을 것인가. `say`는 영수증 얘기를 꺼내지 못합니다.
- 1953년 1월 30일 국제시장 화재로 좌판이 탑니다. 기호는 어느 쪽이든 돈을 갖고 사라집니다.
- 선택 `l2_mother`: 부두에서 아들을 기다리겠다는 시어머니를 데려갈 것인가. `free`는 부르기만 하고 이미 문을 나서고 있습니다.
- 1967년 영등포, 방직공장 십사 년. 영호가 받아 온 답장에는 시어머니가 이재민 명부에 없다고 적혀 있습니다.

### 3장 「6인실」 (`2.yaml`) — 1988년 서울

- 민재(17), 대학병원 6인실. 옆 침대의 수경(21), 새벽마다 오는 엄마.
- 선택 `l3_open`: 엄마에게 무섭다고 말할 것인가. `guard`는 엄마 얼굴부터 살핍니다.
- 선택 `l3_out`: 폐막식 날 밤 수경과 병원을 빠져나가 한강에서 불꽃을 볼 것인가. `stay`는 침대 난간을 놓지 못합니다.
- 가장 짧은 삶입니다. 어둠에서 떠오르는 것도, 쥘 수 있는 것도 적습니다.

### 4장 「녹취」 (`3.yaml`) — 2026년 서울

- 서지안(34), 다큐 「기억하는 사람들」의 녹취 담당. 차윤희 피디, 증언자 오문호(68).
- 선택 `l4_mark`: 세 녹취에 겹치는 말 가운데 어디에 줄을 그을 것인가. '가다가 돌아봤다'를 고르면 `looked_back`.
- 선택 `l4_munho`: 문호가 지안의 전생을 단정합니다(틀렸습니다). 반박할 것인가, 듣기만 할 것인가.
- 선택 `l4_sign`: 정규직 계약과 녹취 원본 양도. `live`는 일어서지 못하고, `dare`는 앉아 있지 못합니다. 이 장에서는 두 방향 모두 이 선택을 빼앗깁니다.
- 엄마의 메시지에는 끝까지 답하지 않습니다. 2071년, 일흔아홉.

### 5장 「360」 (`4.yaml`)

마지막 어둠. 쥘 것을 고르고, `looked_back`이면 가는 도중에 돌아볼 수 있습니다.

## 6. 상태와 결말

| 결말 | 조건 |
| --- | --- |
| 한 점 (`onward`) | 끝까지 가고, 마지막에 쥔 것이 처음 쥔 것과 다르다 |
| 한 바퀴 (`circle`) | 끝까지 가고, `v4`가 `v0`과 같다 |
| 돌아본 사람 (`returner`) | 4장에서 '가다가 돌아봤다'에 줄을 긋고, 마지막에 돌아본다 |
| 머무름 (`still`) | 어느 어둠에서든 쥐지 않기로 하고, 되묻는 말에도 없다고 답한다 |

실패(게임 오버)는 없습니다. 죽음은 다음 장으로 가는 길이고, 멈추는 것도 결말입니다.

## 7. 글쓰기 규칙

- 어둠 장면만 내레이션으로 씁니다. 삶 장면의 정보는 대사, `place`, 서류(`record`), 방송 수치(`system`), 엄마의 메시지(`message`)로 넣습니다.
- 어둠 속의 존재는 방금 끝난 삶만 기억합니다. 이전 어둠을 떠올리는 문장("지난번보다")은 쓰지 않습니다.
- 빼앗긴 선택 장면에서 인물은 까닭을 모릅니다. "빈 독을 본 적은 없다"처럼 모른다는 사실만 적습니다.
- 임종은 "뭐 드시고 싶은 건 없습니까"로 시작하는 짧은 대화로 맺습니다. 죽는 순간은 쓰지 않습니다.
- 돈과 날짜는 그 해의 것으로 씁니다. 1894년은 냥, 1952년은 원(이듬해 2월에 환으로 바뀜), 영수증 날짜는 단기 4285년.

## 8. 미술과 음악

- 그림은 전부 `scripts/generate-360-art.py`가 그리는 SVG입니다. 윤곽선 없는 종이 오림, 시대마다 색 묶음 하나. 인물에는 얼굴이 없습니다.
- 배경 14장: 어둠 둘, 시작 화면, 1894년 둘, 1952~1967년 넷, 1988년 둘, 2026~2071년 셋.
- 인물 10명(자세 포함 12장)과 주인공 자리용 빈 그림 1장, 소품 4종(열쇠·영수증·약봉지 그림·지구본).
- 음악 6곡은 `scripts/generate-360-score.py` 합성음입니다. 어둠에는 가락이 없고, 아주 가까운 두 저음이 8초에 한 번씩 울립니다. 삶마다 음색이 하나씩입니다.

## 9. 무대 규칙

- 주인공(`만석`·`순임`·`민재`·`지안`)은 `assets/char/self.svg`를 쓰고 항상 왼쪽에 섭니다.
- 주인공 대사에는 `with`로 듣는 사람을 적습니다. 빼면 휴대폰 폭에서 빈 자리만 화면에 잡힙니다.
- 같은 선택지 문구를 조건만 달리해 두 번 쓸 수 없습니다. 빼앗긴 선택은 `*_try` 장면에서 `branch`로 갈라 `*_cannot`으로 보냅니다.
