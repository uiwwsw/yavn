# ERASE · 게임 바이블

원작 이야기: 사용자 제공 시놉시스 두 편(「ERASE 개선판」, 「더 잔혹한 버전」). 두 판을 한 편으로 합쳐 YAVN 비주얼노벨로 옮긴 기획서입니다. 인물·사건은 모두 창작이며 실존 인물·기존 작품과 무관합니다.

## 0. 공통 세계와 반전

- **ERASE 시술**: 지난 삶의 기억과 얼굴·이름을 지우고 전혀 다른 사람으로 깨어나게 하는 가상의 시술. 의사(목소리)는 늘 같은 말을 한다. "눈 뜨면… 새로 시작해요."
- **반전**: 오프닝 수술대의 얼굴 없는 인물은 마지막에 **유하린(18)**으로 밝혀진다. 하린은 열여덟에 ERASE를 받고 한도윤으로 깨어났다. 도윤은 그 사실을 기억하지 못한 채, 하린이 그랬듯 견딜 수 없는 것을 지우며 산다. 그리고 다시 ERASE 앞에 선다.
- **주제**: 지우는 습관이 사람을 어떻게 지우는가. 무너뜨리는 것은 질병이나 정체성이 아니라 "통제할 수 없다는 공포"와 그 공포를 지우려는 반복이다.
- **지키는 원칙**
  1. HIV는 벌이나 업보가 아니다. 준성은 치료받으며 살아가던 사람이다. 들킴의 공포를 키우는 그림자로만 쓴다.
  2. 준성의 부재는 응징이 아니다. 행방은 확정하지 않는다.
  3. 성적 장면은 암전으로 넘긴다. 노골적인 묘사 없음.
  4. 옥상 장면은 결과와 방법을 묘사하지 않는다. 시작 화면에 내용 경고, 엔딩에 자살예방 상담전화 109와 보건소 익명 HIV 검사 안내.
  5. 성적 지향은 악역의 원인이 아니다. 도윤의 비극은 숨김과 삭제에서 온다.

## 2. 구성 (`public/game-list/erase/`, 5장)

교차 구조: 현재(도윤) ↔ 과거(하린). 두 번째 판의 소문·협박·준성의 집·진료소를 본편에 녹였다.

- **0장 「완성」**: 수술대 위 얼굴 없는 사람 → 카드 "ERASE" → 청첩장 촬영(식대·보증 인원·계약금 같은 현실 이야기) → 클럽, 준성 → 새벽, 메시지·사진·위치 기록을 지운다 → 준성이 저장한 번호 "아무거나 씨".
- **1장 「같은 군대」**: 팀 단톡방, 새 팀장 준성, "없던 걸로 하죠" → 단톡방 소문에 대한 반응(`e1_rumor`) → 과거: 하린의 교실, 밤의 휴대폰.
- **2장 「소문」**: 청첩장 읽음 표시 → 준성 뒤지기 반복 선택(`e2_dig`: 인스타·메모장·단톡방에 흘리기, 할수록 `cruelty` 상승) → 엘리베이터 협박(`e2_threat`) → 준성 결근과 사무실 뒷말 → 과거: 민재와 아진.
- **3장 「흔적」**: 준성의 집 심부름(`e3_room` 조사: 약 봉투, 치료 기록 "미검출", 달력 "오늘 약 먹었음") → 검색과 아이 사진(`e2_photo`) → 진료소 번호표(`e3_clinic`) → 과거: 핀에 꽂힌 나비, 아진의 "지우지 말고" → 지수와의 대면(`e2_jisu`).
- **4장 「ERASE」**: 옥상 → 동의 장면("확신하세요?" / "네.") → 반전 → 마지막 선택(`e3_final`).

속마음(`thought`)은 네 줄뿐이다. 도윤은 지울 목록과 숫자로만 생각하고, 하린은 휴대폰 타자 속도로 생각한다. 나머지는 행동·말풍선·침묵이 맡는다.

**결말 4종** (`e3_final`)
1. **ERASE** (기본): 전부 지운다. `cruelty` 4 미만.
2. **지워진 이름**: 전부 지운다. `cruelty` 4 이상. 조직도에서 준성과 도윤의 이름이 비고, 단톡방은 "몰라ㅋㅋ 이제 상관없잖아". 벌은 없다.
3. **남겨진 사진**: 아이 사진을 남겼을 때(`kept_photo`). 진료소에 갔는지에 따라 마지막 장면만 달라진다.
4. **완성되지 않은 사람**: 지수에게 전부 말했을 때(`told_jisu` = 2).

## 4. 엔진 연출

- **전체 화면 자막 카드**(`card`): "현재 · 도윤 29", "과거 · 하린 18", "ERASE", 암전.
- **메시지 채널**(`say.channel: message`): 휴대폰 말풍선. `say.side`(me/them)로 좌우, `say.erase: true`면 글이 지워지는 연출.
- 선택은 "무엇을 지울지" 고르는 조사 화면(`presentation: explore`)을 반복 사용해 삭제의 손맛을 만든다.
