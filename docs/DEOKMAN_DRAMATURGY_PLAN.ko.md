# 덕만 드라마투르기 원칙 v6

## 장면

1. 모든 반전은 관찰 가능한 원인, 인물의 반응, 알고도 내린 결정, 결과의 순서로 씁니다.
2. 설정을 먼저 설명하지 않습니다. 곡식 자루, 장부, 도장, 잠긴 문, 인질의 물건이 실제로 움직인 뒤 인물이 의미를 판단합니다.
3. 선택 전에 관계와 대가를 대화로 충분히 보여 줍니다. 인물이 네 선택지의 손익을 차례로 낭독하지 않습니다.
4. 한 사람이 모든 위기를 해결하지 않습니다. 덕만이 한곳을 고를 때 다른 곳을 맡을 사람과 책임을 함께 정합니다.
5. 장 끝은 추상적인 결산이 아니라 다음 갈등을 품은 물건이나 행동으로 닫습니다.

## 대화

1. 질문, 회피, 들킨 사실, 반응 가운데 최소 세 단계를 거칩니다.
2. 말투는 현대 한국어로 자연스럽게 쓰되 왕·공주·신하의 높임 관계를 지킵니다.
3. 왕의 권위는 어려운 고어나 긴 연설이 아니라 짧은 판결과 명령, 책임을 자기 이름으로 남기는 태도에서 나옵니다.
4. 악역은 계획을 친절히 해설하지 않습니다. 칠숙은 질서와 권력 분산을 말하면서 실제로 곡식과 사람을 빼앗습니다.
5. 인물의 상처는 범죄의 면책 사유가 아닙니다. 아진과 비담 모두 원인과 죄를 나누어 판단합니다.

## 비주얼노벨 호흡

1. 생활 대사는 기본 속도로, 되돌릴 수 없는 판결과 이별만 느린 출력으로 재생합니다.
2. `wait`는 장면 전환, 증거가 드러난 순간, 결단 뒤 침묵에만 둡니다.
3. 클로즈업은 들킨 감정과 최종 판단에 사용하고, 여러 사람이 책임을 나누는 장면은 중경이나 전경으로 보여 줍니다.
4. 화자 없는 문장은 시간·공간·군중을 잇는 데 사용합니다. 인물의 속마음을 대신 해설하지 않습니다.
5. 시스템 문구는 모두 격식 있는 존댓말을 사용합니다.

세부 장면과 인물별 말투는 [`DEOKMAN_CINEMATIC_SYNOPSIS.ko.md`](DEOKMAN_CINEMATIC_SYNOPSIS.ko.md)를 따릅니다.
