# 덕만 게임 플레이 검수표

## 수동 주요 경로

- 진엔딩 후보 경로: 프롤로그 `길을 잃은 척 → 유신에게 명단 확인 → 잔 교환`, 1장 `기록고 → 백제 소문 → 역이용`, 이후 정통성·통찰·군사·백성 지지를 균형 있게 선택한다.
- 군권 경로: 국경에서 군량·요새·매복을 택하고 최종장에서 군권 즉위를 택해 폭군/비진엔딩 분기를 확인한다.
- 경쟁자 경로: 진운에게 접근하고 어머니를 구한 뒤 직접 또는 유신으로 암살을 막고, 최종 공동 선언의 엔딩 분화를 확인한다.
- 저세력 법통 경로: 인장을 봉하고 화백 표결을 택해 `왕이었던 한 걸음` 가능성을 확인한다.
- 각 챕터에서 실패 선택 후 `직전 선택으로` 버튼이 해당 선택 게이트로 돌아오는지 확인한다.
- 35개 실패 선택 모두 결과창이 즉시 뜨지 않고, 최소 다섯 대사의 상황 전개와 한 번 이상의 화면 이펙트, 마지막 입력 잠금 뒤에 `gameOver`가 나오는지 확인한다.
- 천명에게 비밀을 맡긴 선택이 `cheonmyeong_trust`만 올리고 `sowon_trust`를 바꾸지 않는지 확인한다.
- 최종 증명 뒤 누적 상태에 따라 균형/군사력/민심/불안정 피드백 중 하나가 나온 뒤 마지막 선택으로 이어지는지 확인한다.
- 10개 인물의 기본 10종과 표정 20종, 총 30개 투명 WebP가 녹색 테두리 없이 표시되고, 2인 대화에서 좌우 실루엣과 의복 색이 즉시 구분되는지 확인한다.
- 장면 첫 등장에서는 참석 인물 전원이 `full` 전신으로 함께 보이고, 정보 대사는 `bust`, 발각·배신·사망·고백이 확정되는 문장만 `closeup`으로 같은 원본에서 전환되는지 확인한다. 단독 클로즈업은 `with: []`가 있는 의도적 컷이어야 하며, 10명 모두 머리나 얼굴이 프레임 밖으로 잘리지 않아야 한다.
- 구도 전환 때 인물이 좌우로 미끄러지거나 다시 등장하지 않고 제자리에서 약 260ms 동안 확대·축소되는지, 표정 교체와 저장 불러오기 뒤에도 직전 구도가 유지되는지 확인한다.
- 덕만 `sad/angry`, 진평왕 `sad/weak`, 천명 `sad/nervous`, 유신 `sad/angry`, 소원 `angry/nervous`, 비담 `smirk/sad`, 칠숙 `smile/angry`, 아진 `nervous/angry`, 진운 `nervous/angry`, 월명 `sad/warning`이 모두 실제 대사에서 호출되고 기본 이미지와 자연스럽게 교체되는지 확인한다.
- 타이틀/달빛 궁정/회랑/화백회의/연회장/침전/밀실/왕좌전/국경 요새/국경 마을이 서로 다른 10개 신라 배경으로 전환되는지 확인한다.
- 인물과 배경에 중국 황실의 용·봉황 원형 문양, 복두, 거대한 한푸식 소매, 붉은 다층 궁문·등롱이나 조선 후기 익선관·당의·갓이 보이지 않는지 확인한다. 631년 신라의 낮은 전각, 좁은 소매 교임, 금동·곡옥, 토기와 흙·나무 재질이 일관되는지 함께 확인한다.
- 덕만은 상대 전제를 질문으로 뒤집고, 유신은 숫자와 보고 책임, 소원은 생활 물건, 비담은 자기비하, 칠숙은 존칭형 협박, 아진은 거리와 시간으로 말하는지 확인한다.
- 각 장에 두 인물이 세 번 이상 말을 주고받는 핵심 장면이 최소 8개 있고, 두 번째 인물의 대사가 첫 대사의 구체적 말이나 감정에 반응하는지 확인한다. 독립된 설명문이나 경구를 한 줄씩 번갈아 말하는 장면은 없어야 한다.
- 진평왕 임종 장면에서 덕만의 안부 확인 → 아버지의 늦은 사과 → 후계 지명을 요구하는 딸의 솔직한 부탁 → 딸의 자격과 삶을 분리해 인정하는 아버지 → `먼저 살아라`라는 마지막 말이 순서대로 재생되고, 각 `wait` 동안 빠른 클릭으로 문장이 건너뛰어지지 않는지 확인한다.
- 덕만·유신·아진은 추론형, 진평왕·칠숙은 절제형, 비담은 낮은 반문형으로 타이핑되고 천명 위기 대사는 `nervous/sad` 리듬으로 덮어써지는지 확인한다.
- 24개 선택 프롬프트가 눈앞의 위기를 먼저 보여 주고, 4개 보기가 모두 짧은 즉시 행동으로 읽히는지 확인한다. 프롬프트 30자·보기 16자 제한을 넘지 않아야 한다.
- `moonveil/embers/crown`이 야간 회랑·불타는 기록·최종 즉위에서 각각 재생되고 모션 감소 설정에서는 움직임이 제거되는지 확인한다.
