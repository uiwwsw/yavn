# 무원(無冤) — 한성 검안록 · 게임 바이블

YAVN 대표 샘플 게임의 기획서입니다. 등장인물과 사건은 모두 창작이며, 시대 배경과 『무원록』의 검시 방법만 역사에서 빌려 옵니다. 실존 인물을 등장시키지 않고, 기존 드라마·소설·게임의 설정이나 캐릭터를 사용하지 않습니다. 그림·음악은 모두 이 저장소에서 직접 만든 창작물입니다.

## 1. 한 줄 소개

1792년 가을 한성. 한글로 풀어 쓴 검시 지침서를 처음 손에 넣은 혜민서 의녀 서연이, 고문으로 자백을 받아 내는 수사 속에서 시신이 남긴 증거로 억울한 사람을 지켜 내는 5장짜리 검시 추리극.

## 2. 왜 재미있는가

- **직접 살핀다**: 사건마다 시신 그림표(시형도)와 현장 그림 위의 조사 지점을 직접 눌러 살핍니다. 정답을 대사로 알려 주지 않고, 본 것을 조합해 플레이어가 판단합니다.
- **옛 과학으로 실험한다**: 『무원록』의 실제 방법(물에 빠진 시신의 입·코 거품, 술지게미로 숨은 멍 드러내기, 불 속 시신의 콧속 그을음, 밥을 닭에게 먹여 독 확인, 상처 폭과 흉기 대조)을 장면 안에서 직접 해 봅니다.
- **잘못 짚으면 사람이 죽는다**: 서두른 판단은 무고한 사람에게 곤장과 처형으로 돌아옵니다. 실패는 항상 선택 직전에 단서를 보여 준 뒤에만 일어나고, 원인이 된 선택으로 바로 돌아갈 수 있습니다.
- **증거로 맞선다**: 포교와 의관의 증언에 소지품의 증거를 제시해 모순을 찌릅니다. 틀린 증거를 내밀면 신뢰가 깎이고, 신뢰가 바닥나면 판이 넘어갑니다.
- **선택이 끝까지 따라온다**: 누구를 살렸고 어떤 증거를 지켰는지가 마지막 재판의 무기와 네 개의 결말을 결정합니다.

## 3. 시대와 장소

- 1792년(정조 16년) 가을~초겨울, 한성.
- 영조 때 엮은 검시 지침서 『증수무원록』을 한글로 풀어 쓴 책이 이 무렵 간행되었다는 사실을 배경으로 빌립니다. 게임 속 책 이름은 『무원록 언해』로 줄여 부릅니다. 한문을 못 읽던 의녀·오작인도 검시법을 읽을 수 있게 되었다는 것이 이야기의 출발점입니다.
- 장소: 혜민서(서민 의료 관청), 한성부 관아, 포도청 옥사, 서빙고(얼음 창고), 형조 대청, 도성 골목과 우물.
- 고증은 분위기와 검시 방법의 정확성에 집중합니다. 관직·제도는 이야기를 위해 단순화하고, 게임 안에서 실존 인물의 이름을 부르지 않습니다(임금은 "전하"로만 언급).

## 5. 전체 줄거리

한명재는 전의감 약재를 빼돌려 가짜 청심원을 만들고, 비단전의 감청색 비단 주머니에 담아 진짜처럼 팔아 왔다. 가짜 약을 먹은 아이들이 죽어 나가자 장부를 본 사람들이 하나씩 입을 닫게 된다. 비단전 침모 분이는 주머니 주문서를 보고, 약방 주인 박씨는 약재 출납을 보고, 한성부 서리 윤길은 검안 기록을 옮겨 적다가 진실에 가까워진다.

서연은 분이의 시신에서 시작해 세 죽음을 하나로 잇고, 고문 자백으로 사형당할 뻔한 덕구를 구하고, 마지막 재판에서 한명재의 거짓을 증거로 무너뜨린다.

## 6. 장 구성 (5장)

각 장은 `조사(시형도·현장 탐색) → 실험(무원록 방법) → 추리(선택) → 대면(증거 제시)` 리듬을 따릅니다.

### 1장 「우물 속 신부」 (`0.yaml`)
- 혼례 전날 밤, 마을 우물에서 비단전 침모 분이가 발견된다. 마을은 "신부가 겁이 나 몸을 던졌다"고 말한다.
- 시형도 조사: 입·코(거품이 없다 → 죽은 뒤 물에 들어갔다), 손톱(감청색 실 보푸라기), 목(멍이 보이지 않는다).
- 실험: 주막의 술지게미와 식초를 덮어 숨은 목 자국을 드러낸다 → 교살.
- 추리: 분이의 오라비를 범인으로 몰면 실패(오라비의 손등과 팔에 긁힌 자국이 없다는 단서를 먼저 보여 준다). "실의 출처를 쫓는다"가 생존 경로.
- 획득: 감청 실, 첫 시장(검안 기록).
- 끝: 실은 육의전 비단전에서만 쓰는 감청색. 여금을 찾아간다.

### 2장 「타 버린 약방」 (`1.yaml`)
- 혜민서 옆 박씨 약방이 불타고 주인이 죽었다. 여금은 분이가 주머니 주문서를 따로 꿰매 두었다고 털어놓는다.
- 시형도 조사: 콧속(그을음이 없다 → 불나기 전에 숨이 멎었다), 손(불을 피한 흔적이 없다).
- 실험: 은비녀 검사는 깨끗하다. 막쇠가 은비녀로는 잡히지 않는 독도 있다고 말한다 → 밥을 입에 물렸다가 닭에게 먹인다 → 닭이 쓰러진다 → 독살.
- 제한 시간 선택: 무너지는 지붕 아래 장부 궤짝과 막쇠 중 무엇을 먼저 끌어낼까(장부를 택하면 막쇠 부상).
- 획득: 탄 장부 조각("청심원 삼백 환 — 한"), 분이의 주머니 주문서.
- 끝: 포도청이 짐꾼 덕구를 방화 살인범으로 잡아갔다는 소식.

### 3장 「곤장 아래 자백」 (`2.yaml`)
- 덕구는 곤장 열 대에 자백했다. 강치수는 사흘 뒤 처결을 서두른다.
- 조사: 박씨 목의 상처 본(종이에 먹으로 떠 둔 탁본). 상처는 오른쪽 위에서 왼쪽 아래로 그어졌다 → 왼손잡이. 상처 폭은 한 치.
- 덕구의 낫은 날 폭이 두 치, 덕구는 오른손으로 짐을 든다.
- 대면: 강치수의 증언에 증거를 제시한다(3라운드). 틀린 증거는 신뢰 1 감소, 신뢰 0이면 덕구 처형 확정(재판은 이어지지만 결말에 반영).
- 함정 선택: 증거 없이 "포교가 범인과 한패"라고 외치면 실패(옥에 갇힌다). 직전에 도원이 "증거 없는 고발은 무고죄"라고 경고한다.
- 획득: 상처 탁본, 덕구의 낫 치수.
- 끝: 덕구는 풀려나지만, 기록을 옮기던 서리 윤길이 사라진다.

### 4장 「서빙고의 얼음」 (`3.yaml`)
- 윤길이 서빙고 얼음 사이에서 발견된다. 몸은 굳어 있는데 시반이 덜 퍼졌다 → 얼음으로 사망 시각을 늦춰 보이게 했다.
- 막쇠가 혼자 얼음 창고 안쪽을 보러 갔다가 돌아오지 않는다.
- 탐색: 얼음 출납부(밤중 반출 기록), 청심원 상자(전의감 인), 왼손 자국.
- 습격: 곰보가 덮친다(`attack`). 제한 시간 선택으로 피하거나 막쇠를 끌어낸다. 2장에서 막쇠가 다쳤다면 선택지가 하나 줄어든다.
- 획득: 얼음 출납부, 가짜 청심원.
- 끝: 출납부의 반출 확인 도장은 전의감 한명재의 것.

### 5장 「무원」 (`4.yaml`)
- 형조 대청. 한명재는 "의녀와 오작인의 말은 증언 자격이 없다"며 재판을 뒤집으려 한다.
- 4라운드 증거 제시: 분이(감청 실·주문서), 박씨(탄 장부·독 실험), 윤길(얼음 출납부·시반), 자백(상처 탁본·낫 치수).
- 마지막 추리: 세 사건을 잇는 한 사람을 고른다.
- 결말 판정 후 엔딩.

## 7. 상태와 결말

| 변수 | 의미 |
| --- | --- |
| `trust_dowon` | 도원과의 신뢰(정수). 5장에서 증언 자격을 지켜 준다. |
| `trust_yeogeum` | 여금과의 신뢰(정수). 5장에서 주문서 원본을 내놓는다. |
| `makssoe_hurt` | 2장에서 장부를 먼저 꺼내 막쇠가 다쳤는지. |
| `makssoe_alive` | 4장에서 막쇠를 구했는지. |
| `deokgu_saved` | 3장 대면에서 덕구를 살렸는지. |
| `credibility` | 대면·재판 신뢰. 3에서 시작해 틀린 증거마다 1 감소. |
| `truth` | 재판에서 맞힌 증거 수. |

결말(우선순위 순):

1. **무원(無冤)** — 진엔딩. `truth ≥ 4`, `deokgu_saved`, `makssoe_alive`. 한명재 단죄, 서연은 검안을 정식으로 돕는 자리를 얻는다.
2. **늦은 무원** — `truth ≥ 4`이지만 덕구나 막쇠를 잃었다. 진실은 밝혔으나 이름 하나를 잃는다.
3. **덮인 장부** — `truth ≤ 3`. 한명재는 풀려나고 서연은 혜민서에서 쫓겨난다. 막쇠가 남긴 메모로 다음을 기약.
4. **침묵의 값** — 3장에서 강치수와 거래(덕구의 사면 대신 사건을 덮기로 함)를 받아들였다. 모두 살지만 진실은 묻힌다.

## 8. 공정한 실패 규칙

- 모든 `gameOver`는 앞선 장면에서 눈에 보이는 단서를 먼저 준다(손등에 긁힌 자국 없음, 도원의 무고죄 경고, 기울어진 얼음 더미 등).
- 실패는 플레이어가 고른 행동의 직접 결과여야 한다.
- `recoverToChoice`로 원인 선택에 바로 돌아간다.
- 선택지마다 "정답" 성향(공개·나눔 등)이 반복되지 않게, 정답 위치와 성격을 섞는다.

## 9. 미술 방향

판화와 민화를 섞은 평면 그림. 사진처럼 보이게 하지 않고, 먹선과 넓은 색면으로 장면의 정보를 분명히 전달합니다.

- **팔레트**(공통): 먹 `#1d1a17`, 한지 `#efe6d2`, 한지 그늘 `#d9ccb0`, 주홍 `#b8432b`, 쪽빛 `#2e4a62`, 감청 `#1f3552`, 황토 `#b88a4a`, 송록 `#4f6b4a`, 밤하늘 `#141c26`, 등불 `#f0b65a`.
- **선**: 먹색 외곽선 2~4px, 끝이 둥근 선. 그림자는 사선 해칭이나 한 단계 어두운 색면으로 처리하고 그라데이션은 하늘·불빛에만 쓴다.
- **질감**: 큰 필터(feTurbulence 등)는 모바일 성능 때문에 쓰지 않는다. 종이 결은 반투명 짧은 선 몇십 개로 표현한다.
- **배경**: 1600×900 SVG. 조사 대상(우물, 장부 궤짝, 얼음 더미 등)은 화면 중앙 가로 15~85%, 세로 20~70% 안에 둔다.
- **인물**: 800×1000 반신(허리 위) SVG, 투명 배경. 정면에서 살짝 비낀 3/4 자세. 얼굴은 민화식 가는 눈과 작은 입, 표정은 눈썹·눈·입 모양만 바꾼다. 인물마다 실루엣과 대표색이 달라야 한다(서연 쪽빛 저고리, 도원 짙은 녹색 단령, 막쇠 황토 베옷, 강치수 검은 철릭과 붉은 띠, 여금 감청 장옷, 한명재 회청 도포와 갓, 덕구 해진 흰 베).
- **증거물**: 400×400 SVG, 한지 바탕 원형이나 사각 카드 없이 물건만. 투명 배경.
- **피할 것**: 보라·남색 그라데이션, 유리 질감, 둥근 카드에 그림자, 반짝이 장식, 이모지풍 아이콘.

## 10. 음악

`scripts/generate-muwon-score.py`가 샘플 없이 사인파·배음·감쇠·잔향을 합성해 24초 모노 루프 4곡을 만든다.

- `night-well`: 1장 밤 우물과 골목. 낮은 지속음과 드문 오음.
- `inquest`: 검안과 실험. 일정한 맥박, 높은 음역 비움.
- `pressure`: 대면·습격. 짧은 반복과 긴장 음정.
- `dawn`: 결말. 열린 5도와 느린 상행.

## 11. 제작 규칙

- 대사는 한 줄 70자 이하, 화면을 설명하지 말고 화면에 없는 것을 말한다.
