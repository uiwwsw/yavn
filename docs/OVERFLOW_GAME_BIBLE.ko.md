# 오버플로 3.0

2033년 서울. 에모스 렌즈가 감정 반응을 숫자로 표시한다. 역의 경보는 실제 폭행을 막은 적이 있고, 사람들은 이미 이 제도를 일상의 안전 장치로 여긴다. 문지완은 학생 때 높은 반응값 때문에 실습을 못 나갈 뻔했다. 아버지는 그에게 밖에서 감정을 숨기고, 말을 하기 전에 셋을 세라고 가르쳤다.

이제 병원은 쓰러진 아버지를 보러 온 지완을 무반응으로 분류한다. 지완은 아버지에게 배운 방법대로 병실 문 앞에서 셋을 센다. 나중에 아버지가 침대 난간을 세 번 두드리고 처음으로 겁났느냐고 묻는다. 그 질문에 답하는 시점은 플레이어가 고른다.

## 장별 진행

| 장 | 사건 |
| --- | --- |
| 1. 보호자 한 분 | 장갑을 주워 주는 사람들 위에 판독값이 뜬다. 개찰구에서는 아버지의 휠체어를 빼내던 남자에게 안전 경보가 울린다. 자기 아버지가 쓰러졌다는 전화를 받은 지완은 병원 입구에서 01을 받는다. 결함을 보고한 뒤 해고된 한수경이 건너편에서 그 숫자를 본다. 두 사람은 1장에서 대화하지 않는다. |
| 2. 같은 01 | 수경이 지완에게 접근한다. 플레이어가 시험 기록과 결함 보고서를 어디까지 읽을지 정한다. 시험 입력 001과 101이 모두 01로 표시된다. |
| 3. 세 번 두드리면 | 지완의 동의로 본인 렌즈의 숫자만 기록한다. 병실에서 아버지가 지완에게 겁났느냐고 묻는다. 같은 시각의 실제 판독에 입력 101과 표시 01이 함께 남는다. |
| 4. 사유란 | 회사 사람들이 수경을 찾아온다. 간호사 세라는 전날 다른 보호자도 같은 표시를 받았다고 말한다. 수경은 본인이 렌즈 검수에 서명했던 사실과 오류 재현 과정을 자기 이름으로 기록한다. 아버지는 예전 지완이 화를 낸 게 아니라 겁먹었다고 교사에게 말했다고 털어놓는다. |
| 5. 다음 사람 | 병원은 지완에게 개인 면회 제한을 바로 풀어 주겠다고 제안한다. 어제 돌아갔던 또 한 사람이 다시 접수대에 온다. 지완은 본인 판독을 어디까지 가져갈지 결정한다. |

## 판독과 증거

역은 높은 표시값을 직원 호출에 쓴다. 병동은 아주 낮은 표시값을 직원 동행이 필요하다는 표지로 쓴다. 두 자리를 전제로 만든 판독 카드는 100을 넘기면 앞자리를 버린다. 101과 001은 카드에서 구별할 수 없다. 병원에 저장되는 면회표, 개발자가 준비한 시험표, 지완이 동의해서 남긴 동시 판독은 서로 다른 기록이다. 원본 수치가 증명하는 것은 카드가 앞자리를 잃었다는 사실이다. 지완이 무슨 감정을 느꼈는지는 지완의 말과 행동으로 다룬다.

## 선택과 결말

아침 전화를 받았는지에 따라 병실에서 지완의 첫마디와 휴대폰에 남은 기록이 달라진다. 접수표를 바로 보여 주었는지에 따라 수경이 진단 연결을 설명하는 방식이 달라진다. 병실에서 겁났다고 답하면 둘이 한 번 일찍 대화를 시작한다. 물부터 건네면 같은 말이 다음 면회까지 남는다.

| 결말 | 선택 |
| --- | --- |
| 공개 | 지완 본인의 판독과 수경이 이름을 건 기술 설명만 공개한다. 병원 밖에서도 검토가 시작된다. |
| 정정 이력 | 지완의 기록에 처음 제한을 받은 이유와 정정 사유를 남긴다. |
| 출입 허용 | 바로 면회할 수 있는 개인 조치를 받고 사건을 닫는다. |
| 이의신청 | 다음 보호자와 함께 수치만으로 면회를 제한하기 전에 직원이 확인하도록 요청한다. 병원은 접수하고 심사 결과는 나오지 않는다. |

원고는 게임 목록의 오버플로 패키지에 있다. 1장부터 5장까지 각각 0.yaml부터 4.yaml이다. 기존 공개판과 장면 및 선택의 구조가 달라 작품 버전을 3.0.0으로 올렸다.

## 그림과 소리

역에서 병실, 비상계단으로 이어지는 SVG 배경에는 탁한 푸른빛과 경보의 주황을 사용했다. 병실에는 종이컵과 난간이 들어가고, 비상계단의 창 뒤로 비에 젖은 아파트 불빛이 보인다. 지완은 출입 태그가 달린 물류 재킷을 입고, 동식은 세로로 짠 카디건을 걸친다. 수경의 코트와 안경, 도겸의 후드, 세라의 근무복도 새로 그렸다. 각 인물은 얼굴 윤곽과 눈매가 다르고, 같은 인물의 표정과 휴대폰 초상에는 그 특징이 이어진다. 표지에는 면회 통제선을 사이에 둔 병실 문과 두 자리 판독값이 나온다.

렌즈의 짧은 판독음과 중간에 멎는 자동문으로 접수 장면을 들려준다. 병실에서 난간을 두드리는 세 소리는 끝 박이 늦다. [게임 에셋](GAME_ART_ASSETS.ko.md)
