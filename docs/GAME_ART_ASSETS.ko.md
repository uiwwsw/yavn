# 게임 배경과 인물 에셋

아래 그림은 각 작품의 원고와 기존 인물 설정을 바탕으로 OpenAI 이미지 생성 도구에서 제작했다. 배경은 1600×900 WebP이며, 인물은 투명 배경의 600×750 WebP다. 새 파일을 기존 장면과 인물 ID에 연결했다.

| 작품 | 새 배경 | 새 인물 |
| --- | --- | --- |
| 오버플로 | 물류 사무실, 병동 간호사실, 동식의 집, 폐점 직전 병원 카페, 지역 뉴스 스튜디오 | 지완의 기본·긴장·동요·휴대폰 자세, 동식의 기본·지친 표정, 수경의 기본·지친 표정, 도겸, 세라 |
| 360 | 제물포 객주 마당과 부산 국제시장 | 봉구, 끝순의 기본·아픈 자세, 복례, 기호, 영호 |
| 8비트 심장 | 윤재의 새벽 방, 수리대가 된 편의점 | 윤재의 표정 4종, 비서 화면 4종, 안드로이드 상태 5종 |
| ERASE | 청첩장 촬영 스튜디오, 수술실과 같은 구도의 후반 장면 | 도윤의 표정 4종, 지수의 표정 3종, 하린의 표정 4종 |
| 무원 | 등잔이 켜진 우물가와 서빙고 | 서연의 표정 4종, 막쇠와 도원의 표정 각 3종 |
| 튜토리얼 | 해수의 방과 그린고시원 304호 | 해수의 표정 4종, 태민의 표정 3종 |

## 이미지 생성 요청

- **오버플로**의 기존 월계역·병동 일러스트에 맞춰 창과 형광등의 은은한 빛, 낮은 채도의 남색과 청록, 직물의 질감을 사용했다. 지완은 작업 재킷, 도겸은 녹색 후드, 동식은 갈색 카디건, 수경은 안경과 남색 코트, 세라는 간호복과 카디건으로 구분했다. [오버플로 게임 바이블](OVERFLOW_GAME_BIBLE.ko.md)
- **360**은 1894년 제물포의 쌀 곳간과 1952년 부산 시장의 천막과 좌판을 겹친 종이 질감으로 표현했다. 인물의 얼굴은 비워 두고, 시대별 옷과 자세로 구분했다. [인천광역시 개항장 자료](https://www.incheon.go.kr/goodmorning/GOOD010101/view?curPage=1&nttNo=2041079&srchCategoryCode=SCN&srchPblicteIssnoCode=202011&srchWord=), [대한민국역사박물관 국제시장 자료](https://archive.much.go.kr/data/01/folderView.do?idnbr=2017026876&jobdirSeq=808)
- **8비트 심장**은 새벽 방의 푸른빛과 정전된 편의점 계산대의 주황 램프를 픽셀 아트로 그렸다. 윤재의 노란 후드와 두 기기의 실루엣을 유지하고, 화면과 표시등으로 상태를 구분했다.
- **ERASE**는 따뜻한 촬영 스튜디오와 청록색 수술 조명을 대비시켰다. 두 수술실 그림은 카메라와 장비 배치를 맞추고 베개와 모니터 표시를 달리했다. 세 인물은 일상복·교복과 절제된 표정으로 그렸다.
- **무원**은 우물가의 거적과 등잔, 짚을 덮은 서빙고 얼음과 왼쪽의 기울어진 더미를 넣었다. 서연의 쪽빛 저고리, 막쇠의 베옷, 도원의 녹색 단령과 사모를 사용했다. [한국학중앙연구원 서빙고 자료](https://encykorea.aks.ac.kr/Article/E0027792)
- **튜토리얼**은 평범한 원룸과 고시원의 좁은 구도를 사용했다. 고시원에는 책상, 모니터 세 대, 종이컵을 뒀다. 해수의 고객센터 유니폼과 태민의 짙은 청록색 후드로 실루엣을 구분했다.

## 음악과 효과음

스테레오 FLAC 음악 27곡과 모노 WAV 효과음 21개는 샘플이나 외부 녹음 없이 합성했다. `python3 scripts/generate-game-audio.py`로 다시 만들 수 있다. FFmpeg가 필요하며 `--game`에 게임 ID를 지정하면 해당 작품만 렌더링한다. 곡의 루프 경계를 맞췄고, 효과음은 대화창에 해당 줄이 뜰 때 재생한다.

| 작품 | 음악 | 효과음 |
| --- | --- | --- |
| 오버플로 | 출근길의 불규칙한 박, 병실의 펠트 피아노, 야간 계단의 빗결 | 진동하는 전화, 렌즈 판독, 중간에 멎는 자동문, 마지막이 늦는 난간 두드림 |
| 360 | 어둠의 맥놀이, 제물포의 뜯는 현, 시장 리드, 병동 오르골, 편집실 건반, 마지막 현과 숨 | 곳간 열쇠, 시장 천막의 불꽃 |
| 8비트 심장 | 펄스와 삼각파, 추격과 데이터센터의 박, 새벽에 느려진 윤재의 선율 | 스위치, 건전지, 본체를 두드리는 두 번의 소리, 카트리지에 부는 숨, 부팅음 |
| ERASE | 차가운 수술실과 청첩장 촬영실의 피아노, 클럽의 킥, 잡음과 옥상 바람 | 동의서의 펜, 셔터, 수술실 모니터 |
| 무원 | 관악기의 숨, 현과 가죽북을 닮은 음색, 서빙고를 지난 뒤의 여백 | 우물 밧줄과 물, 기록 종이, 움직이는 얼음 |
| 튜토리얼 | 형광등 험, 체험판 징글, 어긋난 징글, 서버실 팬 | 알림, 짧은 끊김, 문 두드림, 커지는 팬 |
