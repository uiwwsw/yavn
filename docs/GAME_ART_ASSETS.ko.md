# 게임 에셋

여섯 작품의 시작 화면과 런처에는 같은 표지 원화를 사용한다. 배경, 인물과 표정, 휴대폰 초상, 조사 소품은 작품별 팔레트와 질감을 공유한다. SVG에 직접 그린 표지와 배경을 추가하고, 오버플로 주요 인물의 얼굴과 복장을 다시 그리고, 다른 기존 벡터 원화의 색면과 레이어를 다듬었다. 어두운 장면에서도 인물의 눈과 표정이 보이도록 피부색과 명암을 정리했다. 무원의 공유용 PNG에도 새 표지를 적용했다.

| 작품 | 표지와 장면의 화풍 | 음악과 효과음 |
| --- | --- | --- |
| 360 | 찢은 종이와 오려 붙인 실루엣으로 시대가 겹치는 인상을 낸다. 표지의 다섯 조각은 각각 다른 때의 색을 품고 있다. | 뜯는 현, 시장의 리드, 병동 오르골. 곳간 열쇠와 천막에 붙는 불. |
| 8비트 심장 | 픽셀 격자, 제한 팔레트, 작은 화면의 표시등으로 인물과 기계의 상태를 나눈다. 표지에는 휴대용 게임기가 놓여 있다. | 카트리지 음색과 짧게 끊는 박. 배터리와 플라스틱 본체, 부팅음. |
| ERASE | 인화지와 잘라 낸 사진, 청록색 수술 조명을 쓴다. 따뜻한 촬영실 색이 남아 있는 표지에 두 장의 사진이 포개진다. | 촬영실과 수술실의 피아노, 옥상 바람. 동의서에 닿는 펜, 셔터, 모니터. |
| 무원 | 먹빛 목판의 선, 한지 결, 쪽빛 옷과 등잔의 호박색. 표지에는 우물과 기와, 단서의 붉은 실이 놓인다. | 숨 섞인 관악과 뜯는 현, 가죽북. 우물 밧줄, 기록 종이, 얼음이 밀리는 소리. |
| 오버플로 | 근미래 서울의 낮은 채도, 병동의 푸른 형광등, 경보가 켜질 때의 주황. 표지는 병실 문과 두 자리 판독값을 보여 준다. | 출근길의 불규칙한 박, 병실의 펠트 피아노, 야간 계단의 빗결. 전화 진동, 렌즈 판독, 자동문, 난간 두드림. |
| 튜토리얼 | 고객센터와 고시원의 납작한 형광등 색, 교육 화면의 도면 격자와 주황색 표시. 표지는 같은 책상을 두 방식으로 보여 준다. | 형광등 험, 교육용 징글과 어긋난 반복, 서버실 팬. 알림, 짧은 끊김, 문 두드림. |

음악 27곡과 효과음 21개는 합성 음원이다. 곡별 선율과 장면의 재생 위치에 작품별 음색, 잔향, 스테레오 공간을 적용했다. 음악은 스테레오 FLAC, 효과음은 모노 WAV다. FFmpeg를 설치한 뒤 `python3 scripts/generate-game-audio.py`로 다시 만들 수 있다. `--game`에 게임 ID를 지정하면 해당 작품만 렌더링한다.
