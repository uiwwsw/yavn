- 점검 포인트 D: `3.yaml` 초동 정리 뒤 `routes/hub/1.yaml` 조사 라운지로 이동하는지 확인.

- 점검 포인트 F: 각 라인이 독립 동작하고 종료 후 라운지로 복귀하는지 확인.

- 점검 포인트 H: 네 조사 라인의 첫 질문에서 인물별 접근 선택과 고유 반응이 표시되는지 확인.
- 점검 포인트 I: 정확히 두 명이 노출되는 대화에서 좌우 인물이 화면의 1/2씩을 사용하고, 화자가 바뀌어도 자리를 교환하지 않는지 확인.
- 점검 포인트 J: 타이틀부터 후일담까지 `intro/rain/mystery/tension/reasoning/solvethecase/confession` 7개 음악 큐가 모두 실제 에셋으로 재생되는지 확인.

- 점검 포인트 L: 88도 순서를 기억하면 사건 직전 뚜껑 모순과 `deduction_score +1`, `네 사람의 찻잔`을 고르면 계약 갈등 회상과 `final_confidence +1`로 회수되는지 확인.
- 점검 포인트 M: 선택한 기념품이 취침 전과 TRUE END 후일담에서 같은 물건의 고유 대사로 두 번 회수되는지 확인.

## 2) 권장 플레이 점검 시나리오
1. 전 라인 완료 루트
- 라운지에서 4개 라인을 모두 1회씩 완료.
- 기대: 자동 보너스(`deduction_score +1`, `final_confidence +1`, `trust +1`) 후 결말 이동.
- 세이지에게 기록 검증, 레이코에게 관리 절차, 켄지에게 기록과 진술의 교환, 하루오에게 마지막 의도 보존을 선택.
- 기대: `rapport_score >= 3`일 때 인물 이해 장면과 `final_confidence +1` 추가 보너스.

2. 조기 이동 3라인 루트
- 3개 라인 완료 후 중간 정리 회의 이동.
- 기대: `final_confidence -1` 패널티 적용.

3. 조기 이동 2라인 루트
- 2개 라인 완료 후 중간 정리 회의 이동.
- 기대: `deduction_score -1`, `final_confidence -2` 패널티 적용.

4. 조기 이동 1라인 이하 루트
- 0~1개 라인 상태에서 중간 정리 회의 이동.
- 기대: `deduction_score -2`, `final_confidence -3`, `trust -1`, `mistake_count +1` 적용.

5. 재시도 구조 검증
- 각 라인에서 일부러 오답 선택/입력.
- 기대: 1차 시도 후 재시도 scene 1회 제공, 이후 오답은 실패 라인으로 진행.

6. 결말 지목 검증
- `final_accuse_gate`에서 `세이지/레이코/켄지/하루오 자작극`이 모두 노출되는지 확인.
- 레이코 외 세 지목은 즉시 게임오버 복구 화면으로, 레이코는 증거 확인과 결말 판정으로 이어지는지 확인.

7. 핵심 단서 회복 루트
- 하루오 라인에서 감식 선택을 놓친 뒤 `tea_residue_report`를 보유하고 재방문.
- 기대: `clue_haruo_wipe`, `clue_rim_reagent`, `recovered_haruo_clue` 활성화.
- 레이코 라인을 먼저 실패한 뒤 `clue_rim_reagent`를 얻고 재방문.
- 기대: 증거 제시 장면을 거쳐 `reiko_motive_open` 활성화.
- 세이지 라인의 숫자 입력을 놓친 뒤 재방문.
- 기대: 눌린 자국 확인 장면을 거쳐 `clue_order_note` 활성화.

## 3) 상태값 기반 검증 포인트
- `investigation_count`: 라운드 누적 조사 횟수.
- `visited_*`: 각 라인 진입 여부.
- `early_exit_taken`: 라운지 조기 이동 여부.
- `remembered_tea_order`: 하루오가 알려 준 88도 시음 순서를 기억했는지 여부.
- `tea_name_vote`: 플레이어가 고른 차 이름 후보(`rain/people/detective`).
- `souvenir_choice`: 가족 여행에서 고른 기념품(`paddle/tea/postcard`).
- `deduction_score`, `mistake_count`, `trust`, `final_confidence`: 결말 판정 핵심 수치.
- `rapport_score`: 각 인물의 방어기제에 맞는 질문을 선택한 횟수. 3 이상이면 전 조사 보너스 활성화.
- `rapport_seiji`, `rapport_reiko`, `rapport_kenji`, `rapport_haruo`: 인물별 접근 성공과 후속 대사 분기 플래그.
- `clue_rim_reagent`, `clue_order_note`, `clue_double_press_decoy`, `clue_haruo_wipe`, `reiko_motive_open`: 단서 잠금 플래그.

## 4) UX/연출 체크
- 코난의 `serious/think` 대사는 일정한 추리 리듬, 레이코의 `nervous` 대사는 불규칙한 호흡으로 출력되는지 확인.
- 코고로의 첫 외침은 `shout`, 레이코의 자백은 `sad` 전달 톤으로 구분되는지 확인.
- 세이지는 시간·원본·사본, 레이코는 절차·존댓말, 켄지는 조건·거래 어휘를 일관되게 쓰는지 확인.
- 란이 하루오의 의도를 복원하고 레이코의 회피를 감정적이되 구체적인 말로 짚는지 확인.
- TRUE END에서 켄지의 책임 회피, 레이코의 문장 붕괴, 코고로의 단호한 결론이 서로 다른 리듬으로 출력되는지 확인.
- TRUE END에서 켄지가 하루오의 거래 거절을 밝힌 뒤 레이코가 `들은 말 -> 못 들은 뒷말 -> 묻지 않은 사실` 순서로 무너지는지 확인.
- TRUE END 후일담에서 코고로가 깨어나 허세를 되찾고, 기념품 선택과 탁구 농담이 세 사람의 대화로 회수되는지 확인.
- 말줄임표 뒤 정지가 쉼표·마침표보다 길고, 클릭 즉시 완성 시 글자 반응이 남지 않는지 확인.
- 타이틀에서 엔진 제목이 데스크톱/모바일 `cover` 크롭 모두에서 읽히는지 확인.
- 타이틀과 핵심 배경이 16:9로 표시되며 검은 레터박스나 워터마크성 흔적이 없는지 확인.
- 객실/기념품 코너/탁구 휴게실/식사실/다실/복도/사건 보드/관리실/기록 보관실/산악 외경이 서로 구분되는지 확인.
- 첫 4분 이상 사건 전조 없이 가족 여행의 즐거움이 유지되는지 확인.
- 차 체험에서 하루오의 다정함, 세이지의 마른 유머, 켄지의 내기, 레이코의 자부심이 갈등 전에 드러나는지 확인.
- 기념품·탁구 선택은 정답/감점 없이 가족별 다른 농담으로 이어지고, 시음 순서·차 이름 선택만 이후 관찰과 신뢰에 반영되는지 확인.
- 탁구 장면에 `열한 점 단판`, `열한 대 이`가 없고 `딱 삼세판`, `국제 규칙`, 란의 녹음 농담이 자연스럽게 이어지는지 확인.
- 계약서 갈등은 `1.yaml` 마지막 장면에서만 시작하고 실제 사건은 `2.yaml`에서 발생하는지 확인.
- 코난 독백이 48자 이하이고, 관찰 하나와 다음 행동 하나만 말하는지 확인.
- 코난과 란은 서로 자연스러운 반말을 쓰는지 확인. 란은 아빠와 외부 성인에게 존댓말을, 코난은 코고로·료칸 인물에게 또렷한 존댓말을 유지하며 괄호형 내면 독백은 해체로 구분하는지 확인.
- 대사와 선택지에 `열대일이네/열대야네`, `같은 장면 안에 들어왔어`, `잔과 시각으로 버틴다` 같은 날씨 레이블·요약형 문장이 없는지 확인.
- `0.yaml` 첫 로딩 시 사건 인물과 다실 자산을 받지 않고 핵심 3인과 휴가 배경 6종만 선로딩하는지 확인.
- 사건 발생 후 `flash/darken/shake`와 `scream/thunder`가 어색하지 않게 연결되는지 확인.
- `shake/zoom/tilt/impact` 중 데스크톱·모바일 문서에 불필요한 가로/세로 스크롤이 생기지 않고, CASE FILE 및 긴 선택지 내부 스크롤은 정상인지 확인.
- 최종 범인 선택에서 레이코 외 오답을 누르면 엔딩 크레딧이 아니라 즉시 복구 화면이 표시되는지 확인.
- 켄지·하루오·세이지·레이코 조사에서 첫 오답 뒤 안전한 후퇴 선택은 계속 진행되고, 반박된 추리를 다시 고집하는 선택만 게임오버가 되는지 확인.
- 초동 감식에서 글자 해석을 재고집하거나 현장 재구성에서 주전자 가설을 재확정하면 게임오버가 되고, 정정 선택은 정상 진행되는지 확인.
- 복구 화면의 전체 불러오기·최근 저장·챕터 처음 버튼과 CASE FILE 저장 탭의 자동저장 토글·수동 저장·백업 입출력이 모바일에서도 잘리지 않는지 확인.
- 사건 직후 폴리스 라인이 사라진 다음 `2R` 단서 카드가 단독으로 표시되고, 카드 아래에 캐릭터 일부가 비치지 않는지 확인.
- 같은 위치의 인물이 `base -> emotion`으로 바뀔 때 왼쪽에서 다시 들어오거나 좌우 폭이 흔들리지 않는지 확인.
- 대화 상대가 새로 노출되거나 1인에서 2인 구도로 바뀔 때 옆으로 슬라이드하지 않고, 최종 슬롯에서 짧은 상승·페이드로만 나타나는지 확인.
- 코난+코고로 2인 구도에서 코난만 퇴장할 때 코고로의 절반 위치와 너비가 유지되고 순간이동하거나 커지지 않는지 확인.
- 사건 전 코난/켄지/레이코/하루오의 미소와 세이지의 마른 웃음, 사건 직후 란의 결연함과 코고로의 충격이 장면 의도에 맞게 표시되는지 확인.
- `2R`의 R 꼬리 방향, 레이코의 손수건, 21:29에 멈춘 온도계가 조사와 결말에서 같은 인과로 회수되는지 확인.
- 잠자는 코고로 구간에서 추리 대사가 코난 이름이 아니라 `코고로` 화자로 표시되는지 확인.
- 오답/재시도 장면이 `정답`, `라인`, `채택` 같은 시스템 판정어 대신 진술과 물리 흔적으로 반박되는지 확인.
- 라운지 왕복 시 배경/음악 전환이 튀지 않는지 확인.
- 로컬 오디오 BGM 전환이 약 420ms 크로스페이드되고, 같은 트랙 재지정은 처음부터 재생되지 않는지 확인.
- 새 증거가 없는 재방문은 안내 후 라운지로 복귀하고, 새 증거가 있는 재방문은 회복 장면으로 이어지는지 확인.
- 모바일에서 장소명이 포함된 긴 조사 선택지가 레이아웃을 깨지 않는지 확인.
- 란과 코고로의 도입 대화 및 각 용의자 심문에서 2인 자동 분할이 적용되고, 독백은 기존 1인 중앙/지정 위치를 유지하는지 확인.
- 2인 분할 상태의 이미지·Live2D가 데스크톱과 모바일에서 중앙 경계를 과도하게 침범하거나 잘리지 않는지 확인.
- 탁구 장면의 `그 말, 녹음했어`에서 미란 1장/코고로 1장만, `란 누나, 이번엔 왼쪽`에서 코난 1장/미란 1장만 렌더링되는지 확인.

## 5) 통과 기준
- TRUE/NORMAL/BAD 각 1회 이상 재현.
- 4개 라인 진입/복귀 모두 확인.
- 조기 이동 패널티 3종(3개/2개/1개 이하) 모두 재현.
- 라인별 재시도 1회 구조 확인.
- 핵심 단서 회복 루트 3종 확인.
- 인물 접근 정답 4종과 비정렬 응답 8종 확인.
- `rapport_score` 3 이상/2 이하의 허브 대사와 보상 차이 확인.
- 2인 자동 분할, 2인→1인 생존 인물 배치 유지, 신규 1인 기본 배치, 3인 기존 3열 배치 전환 확인.
- 타이틀 포함 12개 AVIF 배경 파일의 중복 해시 없음.
- YAML 파싱/빌드 에러 없음.
