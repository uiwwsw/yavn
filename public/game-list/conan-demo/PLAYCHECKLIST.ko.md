# Conan Demo 플레이 체크리스트

## 의도

- 시작 버튼 이후 엔딩까지 입력 없이 약 60초 안에 완주한다.
- 7초 제한 선택은 만료 시 첫 옵션으로 자동 진행한다.
- `impact`, `glitch`, `speedlines`, `alarm`, `focus` 연출이 장면 전환을 방해하지 않는다.
- 기존 Conan 에셋은 `root:/game-list/conan/...` 경로로 공유한다.

## 데스크톱

- 시작 화면의 게임명과 `60초 시작` 버튼이 배경 위에서 읽힌다.
- 자동 진행 중 수동 클릭 시 다음 자동 진행 타이머가 중복 실행되지 않는다.
- 제한시간 선택을 직접 누르면 타이머가 즉시 취소된다.
- 엔딩에 `MISSION CLEAR`가 표시된다.

## 모바일

- 390x844에서 제목, 시작 버튼, HUD, 대사, 선택지가 화면 밖으로 넘치지 않는다.
- 제한시간 바와 두 선택지가 대화창 내부에서 스크롤 없이 식별 가능하다.
- 세로 화면에서도 배경 핵심 피사체와 캐릭터가 대화창에 가리지 않는다.
- `prefers-reduced-motion`에서도 자동 진행과 제한시간 분기는 유지된다.
